## ✦ Overview

Welcome to **Anime Adventures Macro Hub** — a centralized collection of macros and automation tools for Roblox Anime Adventures.

Designed to simplify repetitive gameplay, improve farming efficiency and provide convenient tools for different game modes.

From automatic Story farming to Trait rerolls and seasonal event progression, everything is organized in one place.
